# 版本记录

## 0.2.0 — 2026-10-11

- 面向通用嵌入式 Linux 整理工程流程，目标架构、ABI 和平台能力按实际 SDK/设备证据确认。
- 加强 BSP、设备树、Linux 驱动和外设工作流，补充错误回滚、异步退出、DMA 所有权与电源管理参考。
- 明确 13 个技能的主辅路由、正文读取与条件参考规则，整理媒体、Qt、通信、存储和应用运行环境的边界。
- 增加 8 份明确标为合成输入的教学案例。
- 增加有界取证脚本及测试，记录 live/offline 来源、缺失/截断、生产命令状态和报告生成失败。
- 清理没有精确 SDK 依据的厂商执行配方，补充来源、版本和验证范围要求。
- 专家包内附 Apache-2.0 LICENSE，保持原专家标识、Agent 文件名和头像内容。

仓库工具测试覆盖包校验与取证脚本。目标 SDK/内核构建、BusyBox、板卡行为和 WorkBuddy 原生加载不因本次打包而视为通过。原头像规格和展示验证范围见 [README](README.md)。
