> 国科微（Gx）系列常见于视觉与安防类 SoC，编解码通过 **GKMPP** 提供，GStreamer 侧通常有对应 plugin。

## 硬件加速能力

| 引擎 | 用途 | 访问方式 |
|---|---|---|
| **GKMPP** | 视频编解码 | GKMPP API |
| **GStreamer plugin** | 编解码集成（视 SDK 而定） | gstreamer |
| 2D/ISP | 图像处理（视型号而定） | 厂商 API |

## GKMPP 特点

GKMPP 是国科微自研的多媒体处理框架，概念上类似 Rockchip MPP 但**接口与实现完全不同**。

## 通用排查思路（不依赖具体 SDK）

在缺少详细文档时，用这几条通用路径推进：

1. `media-ctl -p` — 确认摄像头链路拓扑
2. `v4l2-ctl --list-devices` / `--list-formats-ext` — 确认节点与格式
3. `dmesg` — 驱动加载与运行时错误
4. `GST_DEBUG=2 gst-launch-1.0 ...` — GStreamer 侧问题
5. `gst-inspect-1.0 | grep -i gk` — 确认可用 plugin

## 与其他平台差异

| 维度 | RK3588 / 全志 / NXP | 国科微 |
|---|---|---|
| 公开文档 | 相对丰富 | **较少**，多依赖厂商提供 |
| 社区资料 | 有 StackOverflow/论坛 | 较少 |
| GStreamer 集成 | 成熟 | 视 SDK 而定 |
| 参考价值 | 可借鉴同类芯片 | **难以类比**，需实测 |

国科微的**文档可得性是主要挑战**——遇到问题时往往需要先拿到官方 SDK 文档才能推进。
