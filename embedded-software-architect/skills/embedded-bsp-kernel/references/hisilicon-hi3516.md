# 海思 HiSilicon Hi3516 BSP 适配

Hi3516 型号与 SDK 版本会影响启动链、内核 ABI、工具链和可选组件。先从发行包、manifest、启动日志与目标文件确认，不根据系列名推断能力。

## 启动链

```
BootROM → [实际使用的 loader 阶段] → Linux kernel + 设备树/其他固件
```

不要仅凭芯片系列推断 bootloader 名称、镜像拆分、加载地址或 MPP 启动方式；从串口启动日志、板级恢复说明和对应 SDK 启动配置确认。

## SDK 结构

```
Hi3516_SDK_Vx.y.z.zkk/
├── Hi3516_SDK_Vxxx/          # SDK 主目录
│   ├── Hi3516_Vxxx/         # 芯片目录
│   ├── MPP/                 # 多媒体平台（私有）
│   ├── IVE/                 # 智能视觉引擎
│   ├── OAL/                 # 操作系统抽象层
│   ├── kernel/              # 内核
│   └── tools/               # 工具
├── Hi3516_Vxxx/mpp_component/   # MPP 组件
├── Hi3516_Vxxx/mpp_sample/      # MPP 样例
└── Hi3516_Vxxx/vencdec_sample/
```

目录树是检索线索，不是 SDK 版本保证。使用包内 README/manifest、构建脚本和文件路径确认内核、bootloader、MPP、IVE、OAL 与样例是否存在及相互对应。

## 候选组件线索

| 标识 | 需在当前 SDK 核实 |
|---|---|
| MPP | 头文件、库、内核接口与型号/版本是否匹配；不要假设与其他厂商同名接口兼容 |
| IVE | 是否包含该组件，目标能力和 SDK 对应版本 |
| OAL | 是否存在、API 与使用它的组件 |
| VO | 是否存在、实际显示路径及内核/用户态接口 |

## 工具链与升级方式发现

不要按芯片系列假定专用刷写工具或编译器前缀。先从 SDK 文档与实际可执行文件确认主机工具、目标架构/ABI、编译器前缀、构建目标和恢复步骤；再检查构建脚本如何生成并打包固件。未确认具体型号、包版本、分区布局和恢复办法前，不提供可执行烧写命令。

## 边界与注意

- 同名或相似组件不表示接口兼容；按当前 SDK 头文件、库和文档核对型号及 ABI。
- 同系列不同型号/版本的 SDK 不应互换，逐项确认兼容范围。
- SDK 交付和升级方式由供应渠道决定；不要以整包替换覆盖本地改动。先记录包版本、校验值、补丁、构建配置和升级文档。
- 具体寄存器/时钟/引脚配置以该型号用户手册为准
