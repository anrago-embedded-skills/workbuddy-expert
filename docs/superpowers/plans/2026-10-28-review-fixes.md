所有实现作者只改分配文件，不提交、不推送、不直接操作设备。根代理拥有测试矩阵、元数据、README、CHANGELOG、发布记录和错误台账。代码和工具测试使用临时夹具，不读主机 proc 冒充目标板，不自动登录 WorkBuddy。

原始四项合成输入归档于 `tests/fixtures/routing-review-021.json`。两个新上下文分别读取冻结 0.2.0 与 0.2.1 候选，原答复和读取自述归档于 `tests/observations/0.2.1-before.md`、`0.2.1-candidate.md`，仅归一化临时目录前缀。

两版均合理区分 socket 生命周期、条件变量等待、蜂窝注册和已注册后的数据上下文；没有诊断/构建/板卡执行。其中 socket 增长场景，旧版标为 networking 主、debug 辅，候选版标为 debug 主、networking 辅，均实际讨论了 socket 关闭路径。候选并未完全满足预设主辅顺序，不能写为所有路由条件已通过，也不能从该单次差异推断改版造成退化。
