# WorkBuddy 磐石专家 0.2.1

日期：2026-10-28。作者：**anrago-nathan**。本版保留 13 个技能标识，包含 50 份参考文档及 8 份明确标为合成输入的教学案例。

## 修正与优化

- 取证脚本将 awk 标记路径改为字面量环境传递，修正反斜杠路径造成的目录外写入和截断状态误报。
- debug/perf 共享一份 PID/TID 与有界采样参考；通过非交互 TARGET_PID/可选 TARGET_TID 配置，禁止错误配置等待 stdin。
- 清理旧 shell 占位符、固定 thermal_zone0、固定日志覆盖和依赖 top 列位置的示例。
- debug、perf 和 networking 入口分别由 331/253/394 行精简为 104/124/39 行，具体命令和实现按条件加载；原有参考路径继续可用。
- 修正 GPIO 线路读取的方向/申请副作用，区分 Matter 配网与 IPv6 运行网络、Thread 本地通信与外部连通，明确 WorkerScript 和目标内核 API 的边界。
- 增加四项混合证据路由输入及场景；离线观察记录见 [实施记录](../superpowers/plans/2026-10-28-review-fixes.md)。少量合成任务不用于推导实际调用率、留存或解决率。
